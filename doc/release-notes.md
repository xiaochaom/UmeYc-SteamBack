## 1.3.2 界面与页面关闭行为

- 左侧区域按 Steam 实际 CSS 视口扣除 Decky 侧栏宽度，与侧栏边缘相接。
- 移除固定按钮及置顶规则，全部存档按备份时间倒序显示。
- 存档详情不显示备注；第一行“恢复存档 / 删除存档”，第二行“保存名称 / 关闭”。旧备注保留。
- 收起侧栏关闭左侧页面及本插件的详情、确认弹窗，重新打开回到游戏列表。
- 移除所有 Deck 通知提示，操作错误显示在插件页面。

首页简化为刷新按钮和游戏列表。点击游戏直接在左侧打开存档面板，右侧保留游戏列表；选择路径也在左侧区域内完成。

## 全部手动备份与新存档页面

- 取消自动备份、游戏生命周期监听、桌面后台监测及所有滚动清理；旧自动开关不再生效。
- 每次点击“立即备份”都创建一份快照，内容不变也可保存。普通、固定及撤销备份全部持续保留，只有手动删除才移除。
- “选择游戏存档”改为 UmeYc-Portal 风格内嵌页面：顶部选择文件夹与刷新，下方完整路径，再下方浏览和选择文件、文件夹；支持 SD 卡、内置存储、多路径及隐藏文件。
- 备份记录逐行列出，按备份时间倒序显示。
- 点击存档弹出详情，可重命名、恢复或手动删除，删除前确认。重命名不改变备份时间或文件标识。
- 插件名称为 UmeYc-SteamBack，兼容旧备份及路径配置。

下载 `UmeYc-SteamBack-1.3.2.zip`，通过 Decky 的 ZIP 安装功能安装，校验文件为 `SHA256SUMS.txt`。

从旧名称 `Steamback` 升级时先卸载旧插件，保留 `/home/deck/homebrew/data/Steamback` 数据目录，再安装新版，避免重复加载。
