## 1.3.4 当前存档时间与账号识别修复

- 备份保存路径下方显示“当前游戏存档时间”，取备份范围内存档文件的最新修改时间，精确到秒，按设备本地时区显示。
- 支持自动识别和自选的文件、多目录；不使用目录时间或备份创建时间。点击刷新或恢复存档后重新读取。
- 修复 Steam 启动时账号尚未加载导致存档路径识别失败的问题：刷新和备份前重新确认当前账号，拒绝账号 0，切换账号时替换旧账号。
- 保持纯手动备份和手动删除，不自动清理，不发送 Deck 通知。

本地 27 项 Python 测试、11 项前端测试及构建通过。Deck 实机已确认《明末》重新识别路径，当前游戏存档时间显示在备份保存路径下方；现有备份与配置文件摘要未变。

下载 `UmeYc-SteamBack-1.3.4.zip`，通过 Decky 的 ZIP 安装功能安装，校验文件为 `SHA256SUMS.txt`。

从旧名称 `Steamback` 升级时先卸载旧插件，保留 `/home/deck/homebrew/data/Steamback` 数据目录，再安装新版，避免重复加载。
