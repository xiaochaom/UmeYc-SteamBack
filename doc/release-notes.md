## 1.4.8 修复启动前云存档检查被跳过

- 修复缓存夸克身份与已验证身份不匹配时，误判“未开启自动云同步”并跳过云端检查的问题；现在先验证当前账号，再读取该账号的游戏开关与同步基准。
- 账号变化、网络失败或配置异常时明确提示，不再静默跳过已开启的同步；保留两端进度冲突时暂停启动及覆盖前本地备份。
- 新增启动前同步结果记录，在游戏页显示是否拉取、无需同步或失败的原因；记录保存在插件数据目录的 `cloud_activity.json`。
- 增加独立客户端上传后重新启动并拉取、缓存身份不匹配、账号变化和断网的回归测试；已使用模拟网盘验证 Deck 与 Windows 同步代码双向互通，真实设备与夸克传输仍需联调确认。

升级后原有存档路径、登录状态、自动云同步开关及本地备份继续保留。不写入 Deck 通知。
