## 1.3.3 原生手柄弹窗与存档路径修复

- 点击游戏打开 Steam 原生存档管理弹窗，支持手柄导航；移除左侧覆盖面板。
- 详情弹窗缩短为一屏可显示的布局，操作分两行：“恢复存档 / 删除存档”和“保存名称 / 关闭”。
- 修复重命名保存后连带关闭游戏管理弹窗的问题：保存只关闭当前详情，管理页保留并刷新名称。
- 自动识别合并指向同一实际目录的兼容路径，避免重复备份；旧备份的恢复路径和目录映射保留。
- 游戏存档路径下方显示实际备份保存路径，兼容旧版 Steamback 数据目录。
- 管理页、详情和删除确认均说明：删除只删除备份，不会删除游戏当前存档。
- 保持纯手动备份、按时间倒序、手动删除；不滚动清理，不发送 Deck 通知。

本地 24 项 Python 文件测试、9 项前端测试及构建通过。Deck 实机已验证路径去重、备份目录显示、原生虚拟手柄导航与重命名关闭行为；物理手柄按键需用户实按确认。

下载 `UmeYc-SteamBack-1.3.3.zip`，通过 Decky 的 ZIP 安装功能安装，校验文件为 `SHA256SUMS.txt`。

从旧名称 `Steamback` 升级时先卸载旧插件，保留 `/home/deck/homebrew/data/Steamback` 数据目录，再安装新版，避免重复加载。
