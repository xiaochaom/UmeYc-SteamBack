## 1.4.1 云存档覆盖与目录选择完善

- 嗅探候选可按父目录选择整个目录，也可只选具体文件；选择会避免目录和其子文件同时配置。
- 修复 Windows 目录路径打包为云存档清单时的分隔符问题，嵌套文件可跨设备下载恢复。
- 下载成功后清理临时云端快照，只保留覆盖前生成的本地撤销备份；自选路径配置可清除并重新嗅探。
- 云端同步 16 项、前端 17 项回归，类型检查、Rollup 构建通过。

## 1.4.0 夸克云存档与存档位置嗅探

- 首页支持夸克扫码登录，登录后显示用户 ID，可退出登录；会话只保存在插件后端的权限受限文件中。
- 每个游戏单独设置“游戏关闭时自动上传云存档”，默认关闭；提供本地同步到云端和云端同步到本地两个按钮。
- 云端根目录自动创建 `UmeYc-SteamBack/<Steam账号>/<游戏ID>`；每次上传保留旧版本，使用 ZIP 清单、SHA-256 和版本索引校验。
- 同时显示本地存档时间、云端存档时间和最近上传时间；云端版本发生变化时要求确认，不静默覆盖。
- 下载云存档时先验证账号、游戏、路径映射、文件大小和摘要，再生成本地撤销备份并覆盖当前存档。
- 找不到路径时可记录游戏存档前后的文件变化，列出候选供用户选择；排除常见缓存、日志、临时文件和符号链接，不自动选路。

本地 54 项 Python 测试、15 项前端测试、类型检查、构建通过。后续已在 Steam Deck 实机验证夸克扫码登录；云端真实文件传输尚未覆盖。
