## 1.4.6 启动前云同步与游戏列表分组

- 每游戏新增“开始游戏前自动云同步”开关，默认关闭。Steam 游戏模式启动请求等待同步成功后继续。
- 本地与云端一致时直接启动；只有本地变化时保留本地；两端均有新进度时暂停并提示手动选择同步方向，避免静默覆盖。
- 同步失败、账号切换或取消启动时不会自动启动；覆盖前保留本地备份。不写入 Deck 通知。
- 游戏列表隐藏 Proton、GE-Proton、Steam Linux Runtime 兼容层。
- 不支持 Steam 云存档的游戏分块显示在上方，支持的在下方。读取本地 Steam 元数据，缺失时归为待确认；两组都支持夸克云同步。

先完成首次手动同步及路径确认再开启自动同步。桌面模式外部命令或其他未经过 Steam 游戏模式 RunGame 的启动入口无法拦截。真实游戏云互通仍需按具体游戏格式验证。
