# 中文游戏存档备份

- 中文操作界面，按“已开启 / 未开启”分组显示游戏，支持折叠和逐游戏开关，默认全部关闭。
- 支持 Steam 云存档识别；识别不到时，可自行选择多个存档文件夹或文件，兼容非 Steam 快捷方式。
- 每款游戏滚动保留最近 10 个普通备份；固定存档不占名额，解除固定后在下一次滚动清理时处理。
- 固定存档可备注，列表显示完整的本地备份时间，支持确认后手动删除普通或固定备份。
- 恢复前生成撤销备份，支持撤销最近一次恢复；保留备份中不包含的其他文件。

下载附件 `UmeYc-SteamBack-1.2.0.zip`，通过 Decky 的 ZIP 安装功能安装，或将其中的 `Steamback` 目录放入 `/home/deck/homebrew/plugins/` 后重启 Decky。`SHA256SUMS.txt` 提供安装包校验和。

安装后需按游戏开启自动备份。自定义路径配置不会自动开启开关。插件内部名称保留为 `Steamback`，不要与上游版同时安装。
