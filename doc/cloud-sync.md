# 夸克云存档：开发状态与验证

1.4.0 已实现本地代码与模拟接口测试，尚未进行夸克真实账号及 Steam Deck 验证，尚未发布。

## 页面

- 首页：登录夸克 → 原生弹窗显示本地生成的二维码；登录后显示夸克用户 ID；可退出登录。
- 游戏页：本地存档时间下方显示云端时间、上传时间、默认关闭的自动上传开关，以及两个方向的同步按钮。
- 游戏页识别失败：查找存档位置 → 开始 → 进入游戏保存 → 退出 → 完成查找 → 勾选候选文件并使用。
- 收起 Decky 侧栏关闭全部插件弹窗；网络任务在后端运行，不依赖弹窗存活。页面重新打开时显示任务结果。插件不使用系统通知。

## 数据与传输

云端目录：`/UmeYc-SteamBack/<Steam Account ID>/<游戏 App ID>/`。夸克账号本身提供网盘空间隔离。

每个版本包括一个 ZIP 和一个 JSON 索引。先上传 ZIP，确认夸克已列出完整文件，再上传版本索引。失败时已有版本继续可用，未完成的上传文件可能留在网盘内，插件不会自动删除。

ZIP 不保存另一设备的绝对恢复路径。清单记录相对路径、来源目录序号、大小、修改时间与 SHA-256。下载校验外层 ZIP 摘要、内部文件摘要、账号、游戏和目录映射后，才导入本地备份并执行带撤销备份的恢复。自选路径需在不同 Deck 上按对应顺序配置，且目标文件必须位于用户当前选择的范围。

源文件修改时间用于“云端存档时间”，上传时间单独记录。相同内容不重复上传。云端有未同步的不同版本时要求显式确认；上传期间再次检查是否有其他设备发布，冲突时不发布索引。夸克网页接口不提供跨设备原子比较更新，因此极端并发不能完全避免两个版本同时发布，但所有版本均保留，且后续同步仍会检测内容差异。

单次上传及解压文件总量上限 2 GiB，最多 50,000 个文件。不会跟随所选目录内的符号链接。下载期间游戏重新启动或 Steam 账号切换时，不覆盖当前游戏文件。

自动上传通过插件全生命周期的后台游戏状态观察器触发，检测到运行 → 退出后，等待两次一致的文件状态再上传，最多等待约 30 秒。没有开启的游戏不上传；启动时已经关闭的游戏不补传。自动任务排队，内容无变化时跳过。需要 Steam/Decky 正常运行；系统直接断电或强制停止插件无法保证上传完成。

## 凭证

- `quark/session.cookies`：后端会话文件，0600 权限，目录 0700；不返回前端、不写入云存档、不打印到日志。
- `quark/identity.json`：最近成功验证的夸克用户 ID，用于恢复后台开关作用域；实际同步前仍验证登录。
- `cloud_settings.json`：按夸克用户、Steam 账号、游戏保存自动上传开关和最近同步摘要。
- `cloud_activity.json`：最近任务结果；关闭并重开页面后可查看。
- 嗅探基线只在插件进程内保存，重启插件后需重新开始。

协议适配参考公开实现所展示的网页端请求格式：[Quark CLI](https://github.com/imeiming/quark-drive)。未使用外部二维码服务，不依赖夸克 TV 只读接口。网页端接口可能随夸克升级变化，真实扫码、Cookie 刷新、分片上传和下载域名需在联调时确认。

## 本地验证

54 项 Python 测试和 15 项前端宿主测试通过。测试全部使用临时文件及模拟夸克接口，没有访问真实网盘或游戏存档。

覆盖：二维码状态与私有会话保存、分页目录、秒传确认、分片签名与 Cookie 隔离、HTTP 错误脱敏、云端完整往返、文件时间保留、撤销恢复、多设备路径映射、冲突确认、上传失败保留旧版本、摘要损坏、ZIP 路径穿越与符号链接、精确文件范围、账号隔离与切换、游戏运行保护、退出上传默认关闭与去重、异步任务、嗅探新增及修改候选和范围上限。

## Deck 回到内网后的实机清单

1. 安装开发包前记录现有数据摘要，安装后核对未变化。
2. 夸克真实扫码，确认用户 ID，关闭全部页面并重启 Decky，验证会话及默认开关。
3. 使用独立测试游戏和临时存档路径完成上传、查看网盘根目录、下载、恢复及撤销，核对内容和两个时间。
4. 验证夸克秒传、普通分片上传、断网和过期登录；失败不应被显示为成功。
5. 每游戏开关默认关闭；仅开启的测试游戏退出后自动上传，重启游戏取消上传。侧栏关闭仍能执行，页面重开可查看结果。
6. 在独立目录模拟云端不同版本，确认提示与旧版保留，不对用户真实游戏执行覆盖测试。
7. 实际启动一个无自动路径的游戏，保存并退出，确认嗅探候选和手柄选择流程。
8. 核对全部新增弹窗手柄导航、侧栏收起关闭、无系统通知；确认后再按用户指令发布。
