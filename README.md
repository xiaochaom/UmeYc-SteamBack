# UmeYc-SteamBack｜游戏存档备份

基于 [geeksville/steamback](https://github.com/geeksville/steamback) 的中文改造版，支持 Steam Deck 的 Decky 插件和 Python 桌面界面。

## 功能

- **中文界面**：备份、恢复、配置、删除和确认提示均使用中文。
- **全部手动备份**：点击“立即备份”保存当前进度；每次点击都新建一份，内容不变也可备份。没有游戏启动/退出自动备份，也不滚动删除。
- **自动识别 + 自行选择**：可识别 Steam 云存档；识别不到或不支持云存档时，通过 Portal 风格的内嵌页面浏览并选择文件、文件夹，支持多路径及隐藏文件。
- **非 Steam 游戏**：列表包含非 Steam 快捷方式，也可手动填写游戏 ID 和名称。
- **名称与时间**：点击存档记录弹出详情，可重命名、恢复或删除；列表显示完整本地备份时间，兼容保留旧备注。
- **手动删除**：普通、固定及撤销备份均只有手动删除才会移除，操作前确认；不会删除游戏当前存档。
- **恢复与撤销**：恢复前保存撤销备份，可恢复到操作前的进度。

## 如何使用

1. 打开 Decky 中的 **UmeYc-SteamBack**，首页只有刷新按钮和游戏列表。点击游戏名称，打开支持 Steam 原生手柄导航的存档管理弹窗。
2. 顶部“选择路径 / 刷新”下方显示当前完整路径，区分自动识别与自选路径；指向同一实际目录的自动识别路径会合并，下方依次显示备份保存路径和当前游戏存档时间。
3. 点击“选择路径”，在内嵌页面顶部选择文件夹、查看路径，然后浏览文件；可以选整个文件夹，也可以点击文件或行右侧加号，选择多个存档路径。保存配置不会生成备份。
4. 点击“立即备份”保存一次当前进度。
5. 下方按备份时间倒序列出存档，点击记录可重命名、恢复或删除。
6. 恢复前退出游戏，在详情中确认恢复；系统会先保存撤销备份。
7. 收起侧栏会关闭本插件的管理、路径及存档弹窗；重新打开从游戏列表开始。插件不发送 Deck 系统通知，错误显示在页面内。

### 保留规则

所有备份持续保留，包括恢复前生成的撤销备份；没有数量上限，也不自动清理。需要释放空间时，在存档详情中手动删除。这里的删除只删除备份，不会删除游戏当前存档。

### 自定义路径说明

- 自动识别只适用于能找到 Steam 云存档清单的游戏；其他游戏需要用户选择实际存档位置，本项目不内置全游戏存档路径数据库。
- 自定义路径优先于自动识别，按所选目录递归备份普通文件，或仅备份指定的单个文件。子目录符号链接不会被跟随。
- 请只选择实际存档目录，避免选择整个游戏安装目录、Proton 前缀或主目录。不能选择备份数据目录及其父子目录。
- 路径不存在、磁盘未挂载时不会生成空备份或清理旧备份。空文件夹等到游戏生成存档后才能备份。
- 移除所有自定义路径并保存后恢复自动识别；已生成的备份保留原始恢复路径。
- 恢复采用**覆盖备份中包含的文件**的方式，不删除后来新增的存档槽位或其他文件。撤销会还原本次覆盖的文件；本次恢复新建的文件会在撤销时移除。
- 列表时间为**备份创建时间**，按设备本地时区显示。
- “当前游戏存档时间”为本次备份范围内存档文件的最新修改时间，精确到秒，按设备本地时区显示；支持自动识别和自选路径。点击“刷新”重新读取，恢复存档后也会刷新。

## 安装 Decky 插件

从 [GitHub Releases](https://github.com/xiaochaom/UmeYc-SteamBack/releases/latest) 下载 `UmeYc-SteamBack-1.3.4.zip`，可使用 Decky 的 ZIP 安装功能；发布页同时提供 `SHA256SUMS.txt` 校验文件。也可以解压后将其中的 `UmeYc-SteamBack` 文件夹放到：

```text
/home/deck/homebrew/plugins/UmeYc-SteamBack
```

手动放置文件后重启 Decky。开发构建可从 GitHub Actions 获取。

从 1.2.0 或上游版升级时，先卸载旧的 `Steamback` 插件，再安装新版，避免重复加载。请保留原有数据目录 `/home/deck/homebrew/data/Steamback`，新版检测到该目录时会继续使用其中的备份与配置；全新安装使用 `/home/deck/homebrew/data/UmeYc-SteamBack`。

## 数据保存

Decky 使用 `DECKY_PLUGIN_RUNTIME_DIR`，桌面版继续使用上游 `steamback` 应用数据目录。主要文件如下：

| 文件 | 用途 |
| --- | --- |
| `custom_games.json` | 用户选择的游戏存档路径 |
| `saves2/*.json` | 备份元数据，包括名称、时间、固定状态、备注、文件清单 |
| `saves2/save_*` | 实际备份文件，多路径使用独立后缀目录 |

兼容读取上游旧备份和自选路径。旧版 `enabled_games.json` 保留原文件，但新版不读取、不再触发自动备份。插件升级前建议另行保留原备份目录。
